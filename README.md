# 📚 Bestselling Books Analysis

## 🎯 Project Overview
This project analyzes bestselling books data to uncover trends in book sales, popular genres, top authors, and reader preferences.

---

## 🧹 Data Cleaning
- Removed duplicates
- Handled missing values
- Corrected data types
- Organized publication and sales data

---

## 📈 Dashboard Features
- Top Selling Books
- Genre Analysis
- Author Performance
- Ratings & Reviews Analysis
- Publication Trends

---

## 💡 Key Insights
- Fiction books dominate bestseller lists
- Certain authors consistently achieve high sales
- Higher ratings often correlate with strong sales
- Book popularity changes over time

---

## 🎯 Recommendations
- Focus on high-performing genres
- Promote highly rated books
- Monitor reader trends for marketing strategies

---

## 🛠️ Tools Used
- Power BI
- Excel
- DAX
- Power Query
